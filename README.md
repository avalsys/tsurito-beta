# Tsurito Beta

Early builds of Tsurito, to try what's next before anyone else. A separate app that installs beside Tsurito and updates only to newer betas.

- **macOS**: Apple silicon, macOS 13 or later
- **Linux**: AppImage for x64
- **Windows**: Windows 10 or 11, x64 and ARM. Windows may warn that it doesn't recognise this app, since it is a pre-release build. Choose More info, then Run anyway.

Get it at https://tsurito.com/download/beta
